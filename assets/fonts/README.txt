AioHUD bundled fonts -- registered PRIVATELY by the plugin at load (AddFontResourceEx, no install).
Each family is under the SIL Open Font License 1.1 : its licence is <Family>-OFL.txt beside its files.
Static weights (300 / 400 / 600 / 700, latin subset) from fontsource (cdn.jsdelivr.net/fontsource).
The plugin reads each file's own family name and weight (some name their 400 "Thin" or "ExtraLight") :
the label used in the config is the file name before the dash (OpenSans -> "Open Sans").
